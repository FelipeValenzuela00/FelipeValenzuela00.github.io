Asistente Financiero

Finanzas para pymes argentinas en pesos y dólares, con saldos que siempre cierran y un asistente con IA que registra movimientos y responde consultas. Finance app for Argentine small businesses in pesos and dollars, with balances that always add up and an AI assistant that records transactions and answers questions.

Producto en desarrollo con Diego Scopetta, en camino a su beta. Product in development with Diego Scopetta, heading to its beta.

El problemaThe problem

Las pymes argentinas suelen llevar sus finanzas en planillas sueltas: varias cuentas, dos monedas con una cotización que cambia todos los días y movimientos que llegan por WhatsApp. Los saldos no cierran y nadie ve el negocio completo. Argentine small businesses often run their finances on scattered spreadsheets: several accounts, two currencies with an exchange rate that changes every day, and transactions that arrive over WhatsApp. Balances don’t add up and nobody sees the whole business.

Qué hiceWhat I did

  • Diseñé el backend en ASP.NET Core 8 con Clean Architecture: API, modelo de datos y CI con GitHub Actions. Designed the ASP.NET Core 8 backend with Clean Architecture: API, data model and CI with GitHub Actions.
  • Implementé el aislamiento entre empresas con Row-Level Security en PostgreSQL (rol de la app sin privilegios y empresa fijada en cada conexión) y la sincronización con Clerk por webhooks firmados e idempotentes. Built tenant isolation with PostgreSQL Row-Level Security (an unprivileged app role, with the tenant set on every connection) and Clerk sync through signed, idempotent webhooks.
  • Construí saldos consistentes bajo concurrencia (bloqueo de filas) y transferencias atómicas entre monedas, con la cotización de la fecha o el monto realmente acreditado. Built balances that stay correct under concurrency (row locking) and atomic cross-currency transfers, using the rate for that date or the amount actually credited.
  • Diseñé el asistente para que la IA nunca toque el dinero: interpreta el texto, pero solo carga movimientos en una bandeja que aprueba una persona, y su respuesta se valida contra el catálogo de la empresa antes de usarla. Designed the assistant so the AI never touches money: it interprets the text but only queues transactions in an inbox a person approves, and its output is validated against the company’s catalog before use.
  • Integré la IA detrás de un adapter para cambiar de proveedor (Anthropic, Gemini, NVIDIA NIM) por configuración, y la evalúo con frases de uso real. Put the AI behind an adapter so the provider (Anthropic, Gemini, NVIDIA NIM) is a config change, and evaluate it against real-world phrases.

Decisiones técnicasTechnical decisions

Row-Level Security en una sola base de datosRow-Level Security in a single database
Aísla los datos de cada empresa en la propia base, sin el costo operativo de tener una base por cliente. Isolates each company’s data inside the database itself, without the operational cost of one database per customer.
Montos en decimal y cotización guardada en cada transacciónDecimal amounts, and the exchange rate stored on every transaction
Cuentas exactas y reportes históricos que no cambian cuando cambia el dólar. Exact math, and historical reports that don’t change when the dollar does.
Saldos incrementales con bloqueo de filasIncremental balances with row locking
Dos gastos simultáneos sobre la misma cuenta no pueden dejar un saldo incorrecto. Two simultaneous expenses on the same account can’t leave a wrong balance.
La salida del modelo es entrada no confiableModel output is untrusted input
El texto del usuario se sanea antes de llegar al modelo, y su respuesta pasa por un parser estricto que solo acepta valores conocidos y cuentas o categorías de la empresa. User text is sanitized before it reaches the model, and its response goes through a strict parser that only accepts known values and the company’s own accounts and categories.
IA detrás de un adapterAI behind an adapter
Cambiar de proveedor es un cambio de configuración, así que puedo comparar modelos con los mismos datos antes de elegir uno. Switching providers is a config change, so I can compare models on the same data before choosing one.

AutoLog

Reconstruye la jornada laboral a partir de Google Calendar, Drive y Jira, y genera un informe diario con IA que se guarda en el Drive del empleado. Rebuilds an employee’s workday from Google Calendar, Drive and Jira, and writes a daily AI report saved to their Drive.

Proyecto final de Analista de Sistemas (ORT Belgrano), en equipo. Team capstone project for the Systems Analyst degree (ORT Belgrano).

El problemaThe problem

Cargar horas a mano es tedioso y poco confiable: al final del día cuesta recordar en qué se fue el tiempo, aunque esa información ya existe repartida entre el calendario, los documentos editados y los tickets de Jira. Logging hours by hand is tedious and unreliable: by the end of the day it’s hard to remember where the time went, even though that information already exists across the calendar, edited documents and Jira tickets.

Qué hiceWhat I did

  • Armé la base del backend: API en Express, esquema y migraciones con Prisma, y Docker. Set up the backend foundation: Express API, Prisma schema and migrations, and Docker.
  • Hice el login con Google y la seguridad de sesiones: cookies HttpOnly, refresh tokens rotativos con detección de reuso y tokens de terceros cifrados. Built Google sign-in and session security: HttpOnly cookies, rotating refresh tokens with reuse detection, and encrypted third-party tokens.
  • Sincronicé Google Calendar y unifiqué las actividades de todas las fuentes en una línea de tiempo. Synced Google Calendar and merged activity from every source into one timeline.
  • Generé el informe diario con Gemini, con la entrada sanitizada y la salida validada antes de escribir la planilla. Built the daily report with Gemini, sanitizing the input and validating the output before writing the spreadsheet.
  • En el frontend (React), corregí el dashboard, el historial, la página de administración y el login con Google, junto con sus tests. On the React frontend, I fixed the dashboard, the history view, the admin page and Google sign-in, along with their tests.

Decisiones técnicasTechnical decisions

Sincronización idempotenteIdempotent sync
Volver a sincronizar el mismo día no duplica actividades: cada una tiene una clave única por usuario, fuente e ID externo. Re-syncing the same day doesn’t duplicate activities: each one has a unique key per user, source and external ID.
Tokens de terceros cifrados con AES-256-GCMThird-party tokens encrypted with AES-256-GCM
El proceso diario sincroniza sin que el usuario esté conectado y sin guardar sus credenciales en texto plano. The daily job syncs without the user being online, and without storing their credentials in plain text.
Refresh tokens rotativos con detección de reusoRotating refresh tokens with reuse detection
Si alguien reutiliza un token viejo, se cierran todas las sesiones de ese usuario. If someone reuses an old token, every session for that user is revoked.
Todo en UTCEverything in UTC
El “día” de cada informe se interpreta en la zona horaria configurada para cada empleado, así el informe no corta la jornada a la medianoche de otro país. Each report’s “day” is read in the time zone set for each employee, so a report never cuts the workday at another country’s midnight.
